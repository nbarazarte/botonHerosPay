Pasarela de Pagos para Heros Technology
Descripción
Este proyecto consiste en el desarrollo de una pasarela de pagos para Heros Technology. La solución propuesta incluye un frontend desarrollado con ReactJS, una API REST utilizando Express, una base de datos implementada con PostgreSQL y la comunicación con la API del Banco R4.

Estructura del Proyecto
Frontend: Desarrollado con ReactJS

Backend: API REST utilizando Express

Base de Datos: PostgreSQL

Integración: Comunicación con la API del Banco R4
